# Fix: [TOOL-006] Type coercion for tool parameters

**Pattern**: type-coercion
**Priority**: P1
**Issue**: #90
**Estimated savings**: eliminates cascading parallel-batch error cancellations (8 errors from 2 root causes in session 1)

## Problem

Agents pass numeric parameters as strings — `"4"` for a radius, `"0.85"` for a color
channel — and the Zod schemas use plain `z.number()`, which rejects strings. When one
call in a parallel batch errors on this, the whole batch is cancelled.

## Fix

Wrap the scalar numeric parameters in the two creation/modification tools in the shared
`numericParam()` helper (`src/figmagent_mcp/utils.ts`), which converts a non-empty numeric
string (`"4"` → `4`) and leaves everything else to the inner `z.number()` chain. `.min()`
/`.max()`/`.positive()`/`.int()` still validate after conversion, and `.optional()`
short-circuits `undefined`.

**Do NOT use `z.coerce.number()` here.** It runs `Number(value)` on *every* input, so
`null`, `""`, `false` and `[]` all become `0` and get applied silently — `opacity: null`
would turn a node invisible, `a: null` would make a fill fully transparent, and a color
missing a required channel would report "Expected number, received nan" instead of
"Required". It also bypasses the plugin's `toNumber(value, fallback)` defaults, which
map `null`/`undefined` to a sensible per-field fallback (opacity → 1, fontSize → 14),
not to 0.

## Changes

Wrap every `z.number()` in both files with `numericParam(...)`. Audited: all occurrences
are scalar design parameters an agent may pass as strings — color channels (r/g/b/a),
dimensions (x/y/width/height), padding, spacing, corner radius, stroke weight, font
size/weight, `index` and `maxLines`. None are array lengths or programmatic counts.

Watch for the multi-line `z\n  .number()` chains (`index`, `fontWeight`, `maxLines`) — a
single-line `z.number()` grep misses them, which leaves `edit({ fontWeight: "700" })`
failing while `write({ fontWeight: "700" })` succeeds.

- `src/figmagent_mcp/utils.ts` — `numericParam()` + the shared `colorSchema` (was
  duplicated verbatim in both tool files; covers the 4 r/g/b/a channels for each)
- `src/figmagent_mcp/tools/apply.ts` — 21 numeric params (17 in-file + 4 color channels)
- `src/figmagent_mcp/tools/create.ts` — 18 numeric params (14 in-file + 4 color channels)
- `tests/boundary.test.ts` — regression guards for the accepted and rejected shapes
