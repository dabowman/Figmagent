# Fix: [TOOL-059] `read` silently skips hidden nodes — an audit reports existing layers as missing

**Pattern**: description-only
**Priority**: P2
**Estimated savings**: ~4 calls per audit on a file with property-toggled layers, plus the wrong answer it prevents

## Background

`read`'s traversal (`src/figma_plugin/src/commands/document.js:458-462`) drops a `visible: false` node and its whole subtree when `filter.visibleOnly` is left at its default, while still counting the node in `meta.nodeCount`. That behaviour is right for layout work and stays. What is missing is the sentence that tells an agent it happened: the `read` description never mentions hidden nodes, and the `visibleOnly` parameter says only *"Skip invisible nodes. Default: true"*.

Session 65 audited components whose Focus rings are hidden until a `Focus` BOOLEAN is on, concluded the rings did not exist, and asked the user to approve building duplicates. It found them only after re-reading with `filter: { visibleOnly: false }`.

## Changes

### File: `src/figmagent_mcp/tools/document.ts`

- Line 288: `Instances are leaf nodes by default — call read on the instance ID to expand its internals.` → `Instances are leaf nodes by default — call read on the instance ID to expand its internals. Hidden nodes (visible: false) are skipped by default, subtree and all, so a layer that only shows when a BOOLEAN component property is on (a Focus ring, an optional icon) will not appear; the skipped node still counts in meta.nodeCount. Before concluding a layer is missing, re-read with filter: { visibleOnly: false }.`
- Line 322: `visibleOnly: z.boolean().optional().describe("Skip invisible nodes. Default: true"),` → `visibleOnly: z.boolean().optional().describe("Skip invisible nodes (visible: false) and their subtrees. Default: true. Set false before concluding a layer is missing — layers toggled by a component property, such as Focus rings, are hidden by default."),`

The line-288 replacement stays inside the existing template literal; it adds no backtick and no `${`.
