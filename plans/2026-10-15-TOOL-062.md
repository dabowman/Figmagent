# Fix: [TOOL-062] `edit`'s `variables` description lists a subset of the bindable fields

**Pattern**: `description-only`
**Priority**: P2
**Estimated savings**: ~2-3 `run_script` calls per token-binding pass on a design system with a size scale or per-corner radius tokens

## Problem

`edit`'s `variables` map accepts every field in `variableFieldEnum` (`src/figmagent_mcp/tools/apply.ts:7-38`), which mirrors `FIELD_MAP` in `src/figma_plugin/src/commands/styles.js:1150-1181`. The parameter description at `apply.ts:207` lists only part of that enum. It leaves out `topLeftRadius`, `topRightRadius`, `bottomLeftRadius`, `bottomRightRadius`, `counterAxisSpacing`, `minWidth`, `maxWidth`, `minHeight` and `maxHeight`. Session 66 bound `minHeight` to a size scale across 16 component sets in `run_script` (`toolu_01EX6B1DJ6ztqMZf2MJ9hDss`) because nothing in the description said `edit` could do it.

The binding code is correct; only the text changes.

## Changes

### File: `src/figmagent_mcp/tools/apply.ts`

In the `variables` field of `nodeOpSchema` (the `.describe(...)` string at line 207), replace this exact text:

```
"Map of field names to variable IDs. Binds design tokens to node properties. Fields: fill, stroke, cornerRadius, padding*, itemSpacing, width, height, opacity, visible, characters, fontSize, fontFamily, fontWeight, fontStyle, lineHeight, letterSpacing, paragraphSpacing, paragraphIndent. NOTE:
```

with:

```
"Map of field names to variable IDs. Binds design tokens to node properties. Fields: fill, stroke, opacity, cornerRadius (binds all four corners), topLeftRadius, topRightRadius, bottomLeftRadius, bottomRightRadius (one corner each), padding*, itemSpacing, counterAxisSpacing, width, height, minWidth, maxWidth, minHeight, maxHeight (e.g. a size-scale token as a control's min height), visible, characters, fontSize, fontFamily, fontWeight, fontStyle, lineHeight, letterSpacing, paragraphSpacing, paragraphIndent. NOTE:
```

Everything from ` NOTE:` onward in that string stays byte-identical. No other line changes.
