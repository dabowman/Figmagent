# Fix: [TOOL-058] `set_multiple_annotations` requires a containing `nodeId` the plugin ignores

**Pattern**: description-only
**Priority**: P2
**Estimated savings**: ~7 calls per annotation pass

## Background

`set_multiple_annotations` declares a required top-level `nodeId` described as *"The ID of the node containing the elements to annotate"*. The plugin handler never reads it — `setMultipleAnnotations` (`src/figma_plugin/src/commands/scan.js:650-654`) destructures only `{ annotations }` and loops, passing each `annotation.nodeId` straight through. The description implies a containment constraint that does not exist, and in session 64 that made a cross-page batch of 9 annotations look impossible; the agent wrote 9 single `set_annotation` calls instead.

## Changes

### File: `src/figmagent_mcp/tools/comments.ts`

- Line ~267: make the parameter optional and state what is true.

  ```diff
  -    nodeId: nodeIdParam().describe("The ID of the node containing the elements to annotate"),
  +    nodeId: nodeIdParam()
  +      .optional()
  +      .describe(
  +        "Optional and unused — kept for backward compatibility. Each annotation is addressed by its own " +
  +          "annotations[].nodeId; the targets need share no common ancestor and may span different pages.",
  +      ),
  ```

- Line ~317: the handler already forwards `params` to `sendCommandToFigma("set_multiple_annotations", { nodeId, annotations })`. Confirm `nodeId` being `undefined` is harmless on both transports (the plugin ignores it; `remote/domains.ts` routes on the command name, not the payload). No change expected — verify only.

- Tool description (the `server.tool` summary string, currently `"Set multiple annotations parallelly in a node"`): replace with one that names the cross-page capability, e.g.
  `"Set annotations on many nodes in one call. Each entry targets its own nodeId — the nodes need not share a parent or a page. Prefer this over repeated set_annotation calls."`

### File: `src/figmagent_mcp/tools/comments.ts` (`set_annotation` description)

- Add a pointer so the batch tool is discoverable from the single one: *"To annotate several nodes, use `set_multiple_annotations` — one call, any number of nodes, across pages."*
