## Problem

`combineAsVariants` (`src/figma_plugin/src/commands/components.js`) pre-checks existence, COMPONENT type and `Property=Value` naming, each with `fail(message, fix)`, but not that every component shares a page with the parent — so Figma's raw `in combineAsVariants: Grouped nodes must be in the same page as the parent` escapes with no fix and no indication of which component is elsewhere.

## Changes

### File: `src/figma_plugin/src/commands/components.js`

After `parent` is resolved (the `let parent = figma.currentPage; if (parentId) {...}` block) and before `figma.combineAsVariants(components, parent)`:

```js
  // Figma requires every component to be on the parent's page; its own error
  // names neither the component nor a fix (BUG-036).
  const parentPage = pageOf(parent);
  for (let i = 0; i < components.length; i++) {
    const compPage = pageOf(components[i]);
    if (parentPage && compPage && compPage.id !== parentPage.id) {
      fail(
        "Component '" + components[i].name + "' (" + components[i].id + ") is on page '" + compPage.name +
          "' but the parent " + parent.id + " is on page '" + parentPage.name + "'",
        "clone it onto the parent's page first with write({ fromNodeId: '" + components[i].id + "', parentId: '" + parent.id +
          "' }) and combine the clone, or pass a parentId on the components' own page",
      );
    }
  }
```

`pageOf` already lives in `src/figma_plugin/src/helpers.js:68` and `components.js:3` already imports it — no import change and no new definition.
