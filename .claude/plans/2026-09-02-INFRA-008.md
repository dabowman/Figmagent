```markdown
## Remote Transport Gotchas

The remote transport runs your writes in a headless `use_figma` VM. It behaves differently from the desktop plugin in ways that cost whole sessions when discovered live:

- **No custom or licensed fonts.** The VM has Google fonts and Inter. A design-system family (e.g. PP Neue Montreal) will not load; every write that touches text on it — `characters`, `textAutoResize`, `appendChild`, `insertChild`, `clone`, `setProperties`, applying a text style — throws "unloaded font", and Figma's own fix ("call loadFontAsync") cannot succeed. Decide the font strategy before the first write script: check `get_design_system({ includeFonts: true })` once it exists, or probe `listAvailableFontsAsync` against the file's text styles. If Figma desktop is open, prefer the plugin transport for a custom-font file.
- **Park, write, re-bind — at node level.** Author text on an available face, do the write, then bind the `fontFamily` variable **last**; the binding survives even though the VM cannot render it. Restore order for a node: set face → bind `fontSize` → bind `fontWeight` → **set the face again** (the weight lookup rewrites it) → set `lineHeight`/`letterSpacing` → bind `fontFamily`. Parking a node's `fontName` silently detaches its `textStyleId` — re-read and re-apply after any park.
- **Width-safe donor faces.** `Inter`/`Regular` for 400; `Noto Sans New Tai Lue`/`Semibold` for 600 (spelled like most design-system Semibolds); `Noto Looped Thai`/`Extrabold` for 800. `SF Pro` and `SF Compact` are listed and loadable but text on them measures **0 width** and exports blank — never use them as donors. Verify a donor by setting `characters` and reading `width`.
- **Styles restore differently from nodes.** For a shared text style: unbind `fontWeight`, unbind `fontFamily`, park `fontName`, do the work, re-bind `fontFamily`, re-bind `fontWeight`, **stop** — do not re-set `fontName` after the weight bind on a style (from the VM the lookup no-ops and the write drops the binding you just made). Parking a style touches every consumer in the file for the script's duration, and an atomic rollback does **not** restore a style's stripped bindings — after any failed park, re-read every style you touched. Prefer node-level parking unless the operation is on the style itself.
- **Text styles self-heal, nodes do not.** A style authored on the wrong face re-resolves when opened in a client that has the font; a node stays on the authoring face's spelling. Put text on text styles, never per-node font properties.
- **Opacity variables are 0–100.** A token authored 0.4 binds as 0.4% and the node disappears. `lineHeight`/`letterSpacing` bindings force unit PIXELS — leave those as PERCENT literals.
- **`figma.currentPage` is shared and does not persist.** It is whatever page the file was last on, it is reset between `run_script` calls, and on remote every connected process sees the same pointer. Pass `parentId` on every create/clone/combine; set the page inside any script that relies on it. Until BUG-047 ships, run sessions on one file serially.
- **`setBoundVariableForPaint` keeps the literal colour.** The binding lands, but the export renders the stored literal — a `{0,0,0}` seed renders black. Build the paint from `variable.resolveForConsumer(node).value` and then bind (BUG-043 will do this inside `edit`).
- **Missing APIs.** `figma.loadAllPagesAsync` and `figma.createNodeFromSvgAsync` do not exist (use `getNodeByIdAsync` and the sync `createNodeFromSvg`). There is no `figma.grepNodes` — use the `grep` tool. Feature-detect with `fig.prop` or try/catch; the strict guard throws on a missing `figma.*` property.
- **`screenshot` on remote.** A whole COMPONENT_SET often returns no data regardless of scale; export single variants, and stop changing `scale` after two failures.
- **Verify a write with the surface that made it.** A `run_script` that returns its own readback needs no second verification read; `get_reactions` and `lint` are the exceptions worth a re-run.
- **Under deferred tool schemas** (any repo but Figmagent's own), before writing a `run_script` in a Figma domain you have not fetched — tokens, styles, components, annotations, libraries — spend one `ToolSearch` on that domain. `create_styles`, `update_styles`, `combine_as_variants` and `component_properties` cover most of what those scripts re-implement.
- **Close out against a re-run of `lint`**, not the first run's summary buckets, after any fix pass.
```
