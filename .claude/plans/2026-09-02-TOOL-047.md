# Fix: [TOOL-047] `combine_as_variants` asserts over the children it re-parented and reports their sizing

**Pattern**: `assertion`
**Priority**: P2 — not auto-dispatched at P2 for this pattern; the plan is for a person
**Estimated savings**: ~2 calls per component set
**Issue**: https://github.com/dabowman/Figmagent/issues/182 — decision comment of 2026-09-02 (part (b); part (a) `name` shipped in PR #194)

## Problem

`combineAsVariants` gives the new set auto-layout, which re-flows every variant, and returns only `{ id, name, type, childCount, children: [{ id, name, type }] }`. Session 59 screenshotted, re-asserted FIXED sizing on all six variants, and screenshotted again — a loop nothing in the response pre-empted. Post-write assertions inspect the node that was written, not siblings a layout change re-flowed.

## Changes

### File: `src/figma_plugin/src/commands/components.js`

Imports: add `import { checkNodes } from "../assertions.js";`, and extend the existing helpers import
(line 3 is `import { fail, pageOf, importComponentByKeyOrFail } from "../helpers.js";`) with `prop` — the
snippet below calls `prop()` and the file does not import it today. Biome does not enable
`noUndeclaredVariables`, so lint and `build:plugin` both pass on the missing import and every
`combine_as_variants` call throws `ReferenceError: prop is not defined` at the return.

In `combineAsVariants`, after the auto-layout block and the `if (name)` line, replace the `return` with:

```js
  // The auto-layout just applied re-flowed every variant; assert over the
  // children, not the set (TOOL-047 (b)). Advisory only.
  const childIds = componentSet.children.map((c) => c.id);
  let warnings = [];
  try {
    // The variants' own heights predate this call — exempt them from the
    // balloon check so combine doesn't blame itself for pre-existing sizing.
    warnings = await checkNodes(childIds, { explicitHeightIds: childIds });
  } catch (_e) {
    // assertions are best-effort
  }
  const out = {
    id: componentSet.id,
    name: componentSet.name,
    type: componentSet.type,
    childCount: componentSet.children.length,
    children: componentSet.children.map((child) => ({
      id: child.id,
      name: child.name,
      type: child.type,
      layoutSizingHorizontal: prop(child, "layoutSizingHorizontal"),
      layoutSizingVertical: prop(child, "layoutSizingVertical"),
      width: prop(child, "width"),
      height: prop(child, "height"),
    })),
  };
  if (warnings.length > 0) out.warnings = warnings;
  return out;
```

### File: `src/figmagent_mcp/tools/components.ts` — `combine_as_variants` handler

Import `formatWarningsBlock` from `../utils.js` (as `tools/apply.ts` does). Split `warnings` off the payload before serialising — `const { warnings, ...summary } = result;` then `JSON.stringify(summary) + formatWarningsBlock(warnings)`, exactly as `tools/create.ts:235` and `tools/apply.ts:361,378` do. Appending the block without stripping the field emits every warning twice. Add one sentence to the description: "Returns each variant's post-wrap sizing (`layoutSizingHorizontal/Vertical`, `width`, `height`) and a `warnings:` block from the post-write assertions run over the re-parented variants."

### File: `tests/combine-as-variants.test.ts` (new)

Mock `figma` with `getNodeByIdAsync` returning two COMPONENT nodes named `Size=SM` / `Size=MD` on a PAGE parent, `combineAsVariants` returning a set object whose `children` are those nodes with `layoutSizingHorizontal: "HUG"`, `width: 100`, `height: 100`, and `currentPage`. Assert the result's `children[0]` carries `layoutSizingHorizontal`, `width`, `height`. Do **not** assert a `balloon_height` warning: this plan passes `explicitHeightIds: childIds`, which exempts the children from that check on purpose (their heights predate the call). For the warnings path assert a `zero_width_text` entry instead — a child `{ type: "TEXT", width: 0 }` triggers `isNearZeroWidthText` with no extra mock fields. (`isBalloonFrame` needs `layoutMode` !== "NONE", `height === 100` **and** `counterAxisSizingMode: "FIXED"` — not the HUG the old wording described.)
